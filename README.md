# 👑 Королевские Интриги (Hot-Seat Strategy)

Пошаговая экономическая стратегия на 4 игроков в режиме "hot-seat" (игра за одним экраном). Игроки управляют своими королевствами, балансируют между распределением ресурсов и пытаются выжить под давлением случайных кризисов и пакостей со стороны соседей. Проект написан на Python с использованием библиотеки Pygame.

---

## 🚀 Как запустить игру

### 1. Подготовка окружения
Убедитесь, что у вас установлен Python 3.8 или новее.

### 2. Установка библиотек
Склонируйте репозиторий, перейдите в папку проекта и накатите зависимости:
```bash
pip install -r requirements.txt
```

### 3. Старт
Запустите главный скрипт:
```bash
python main.py
```

---

## 🕹️ Коротко о геймплее

* **Старт:** 4 игрока получают по одинаковому набору ресурсов (зерно, золото, земля, население).
* **Каждый ход делится на две фазы:**
  1. **Неуправляемое событие:** Рандом выкидывает карточку (засуха, набег купцов и т.д.), которая может сработать как в плюс, так и в жесткий минус с вероятностью 50/50.
  2. **Действие игрока:** Активный игрок выбирает, как уколоть или с кем объединиться из соперников (торговля, кража ресурсов, пропаганда).
* **Финал:** Побеждает тот, кто первым наберет 30 очков престижа или останется единственным выжившим. Если уровень Смуты доходит до 10 или вымирает весь народ — королевство проигрывает.
