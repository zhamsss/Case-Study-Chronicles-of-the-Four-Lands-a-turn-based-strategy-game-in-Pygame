# Геймдизайн-документ (GDD) — Hot-Seat Стратегия

Документ фиксирует правила, математический баланс, экономическую модель и логику поведения сущностей для пошаговой мультиплеерной стратегии.

---

## 1. Базовый цикл и концепт
Игра рассчитана на 4 игроков (королевства), которые управляют ресурсами. Каждый ход состоит из одного неуправляемого события и одного управляемого действия, направленного на взаимодействие с другими игроками.

**Структура одного игрового хода:**
1. Переход хода к текущему игроку.
2. **Фаза неуправляемого события:** Перед ходом `random.choice()` выбирает событие, а `random.random() < 0.5` определяет, будет ли оно применено в позитивном или негативном ключе (если событие нейтральное — применяется как есть). Результат выводится в модальное окно.
3. **Фаза управляемого действия:** Игрок выбирает одно из доступных действий взаимодействия с другими игроками. После выбора действия появляется выбор цели (3 кнопки). Если ресурсов на действие не хватает, кнопка становится неактивной (серой).
4. Запись результатов действия в лог событий на экране.
5. Проверка условий окончания игры для игрока. Задержка 1.5 сек и переход к следующему игроку.

---

## 2. Экономическая модель и ресурсы

Каждое королевство на старте имеет фиксированный набор ресурсов.

| Ресурс | Описание | Старт |
| :--- | :--- | :---: |
| 🌾 Зерно | Еда, влияет на выживаемость | 10 |
| 💰 Деньги | Валюта для торговли и подкупа | 10 |
| 🏞 Земля | Территории, влияют на доход | 5 |
| 👥 Народ | Население, рабочая сила и армия | 10 |
| 🔥 Смута | Негативный ресурс, при 10 — поражение | 0 |

### Формула расчета Престижа (Prestige)
Престиж пересчитывается в реальном времени:
`prestige = land*2 + money//5 + people//5 - smuta`

### Критерии окончания игры
* **Условия победы:** Набрать 30 очков престижа или остаться последним, у кого смута < 10.
* **Условия поражения:** Смута ≥ 10 или народ ≤ 0.

## 3. Пул неуправляемых событий (EVENTS)

Перед началом фазы действия игрока движок выбирает событие из следующего списка:

| ID | Название | Эффект | Тип |
| :--- | :--- | :--- | :--- |
| E1 | Пожар | −3 зерна, −1 земля | Отрицательное |
| E2 | Неожиданная прибыль | +5 денег | Положительное |
| E3 | Эпидемия | −3 народа, +2 смуты | Отрицательное |
| E4 | Урожайный год | +5 зерна | Положительное |
| E5 | Восстание крестьян | +3 смуты, −2 зерна | Отрицательное |
| E6 | Щедрый купец | +3 денег, +1 земля | Положительное |

---

## 4. Доступные управляемые действия (ACTIONS)

Действия направлены на взаимодействие с выбранным игроком-целью. Активный игрок не может выбрать целью самого себя.

| ID | Действие | Стоимость | Эффект |
| :--- | :--- | :--- | :--- |
| A1 | Торговля | −3 деньги | Обменять 3 деньги на 4 зерна у выбранного игрока (он получает 3 деньги) |
| A2 | Подкуп | −5 деньги | Снизить смуту цели на 2, повысить свою на 1 |
| A3 | Набег | −2 народ | Отнять 3 зерна у цели, +1 смута себе |
| A4 | Союз | −2 зерна | Оба игрока получают −1 смуты |
| A5 | Пропаганда | −3 деньги | Переложить 2 смуты на выбранного игрока |
