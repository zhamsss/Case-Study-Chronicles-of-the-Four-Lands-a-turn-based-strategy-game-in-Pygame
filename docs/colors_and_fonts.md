## 7. Экран победы
- Затемнение: чёрный `#000000`, прозрачность 160 из 255. Закрывает только поле, панель остаётся видна.
- «Победил игрок N!»: цвет победителя, размер 80.
- «R — новая игра»: `#FFFFFF`, размер 36.

## 8. Шрифты
Везде шрифт pygame по умолчанию (`pygame.font.Font(None, размер)`, файл freesansbold). Кириллица отображается.

| Размер | Где используется |
|---|---|
| 80 | заголовок победы |
| 36 | «Конец хода», «Игрок N», «Информация», подсказка «R — новая игра» |
| 28 | текст панели (ход, золото, доход, армия, земли, данные клетки и юнита) |
| 26 | кнопки магазина («Название — цена») |
| 22 | подсказка внизу панели |

## 9. Размеры и раскладка
Экран 1600×900, 60 FPS. Поле 1280×900, боковая панель справа шириной 320. Гекс на экране 56×56 (умножается на масштаб 0,6–2,0), шаг по горизонтали 56, по вертикали 42, нечётные ряды сдвинуты вправо на полклетки.

**Размер спрайта относительно клетки:** гекс 100 %, юнит 86 %, дерево 80 %, башня 80 %, столица 79 %, ферма 75 %, надгробие 70 %.

**Слои клетки сверху вниз:** гекс, дерево, надгробие, ферма, башня, столица, юнит, подсветка.
